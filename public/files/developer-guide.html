GitHub & Vercel Static Asset Guide

This standalone HTML document demonstrates direct static file hosting inside public/files/developer-guide.html.

1. Updating the Company Logo

Upload or overwrite public/brand/logo.png in GitHub. Push or commit to your main branch and Vercel automatically redeploys with the updated logo across all pages.

2. Adding a Privacy Policy

Upload any HTML or TXT file under public/privacy-policy/<app-slug>/. For example:

  • public/privacy-policy/multi-tool-app/index.html → /privacy-policy/multi-tool-app/index.html
  • public/privacy-policy/another-app/policy.txt → /privacy-policy/another-app/policy.txt

3. Publishing Downloadable Files

Place PDF, TXT, JSON, HTML, or image assets inside public/files/. Directory structure and filenames are preserved automatically on Vercel.
